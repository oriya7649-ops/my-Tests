# QA Automation Classwork t2

This repository is dedicated to classwork and exercises completed during a QA Automation course.


## Overview

The purpose of this repository is to store practical assignments, scripts, test cases, and notes related to software testing and automation. It is intended to track learning progress in areas such as:

- Manual testing concepts
- Test case design
- Automation frameworks
- Selenium/WebDriver
- API testing
- JavaScript or Python-based test automation
- Bug reporting and QA best practices

## Repository Goals

- Practice core QA automation skills
- Document learning progress throughout the course
- Store reusable examples and exercises
- Build a portfolio of work completed in class

## Structure

This repository may include:

- Test scripts
- Automation exercises
- Notes and study material
- Sample projects
- Configuration files
- Assignments and results

## Getting Started

1. Clone the repository to your local machine.
2. Open the project in your editor.
3. Review the files and complete the assigned tasks.
4. Run the relevant tests or scripts as needed.

## Notes

This repository is a learning workspace for QA automation classwork and may evolve over time as new assignments and projects are added.
